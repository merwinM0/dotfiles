# Fish 函数

## 本目录中的函数

| 函数 | 作用 | 用法 |
| --- | --- | --- |
| `tmkeys` | 切换当前 tmux 窗格的 Alt 快捷键归属 | 见下表 |
| `select_pac_or_aur` | 选择 AUR 安装、仓库安装或卸载命令 | 在交互终端按 `Alt+i` |
| `wechat` | 使用兼容 Fcitx5 的环境启动微信，参数原样传入 | `wechat` 或 `wechat 参数` |

## tmkeys

| 命令 | 作用 |
| --- | --- |
| `tmkeys` | 查看当前模式 |
| `tmkeys tmux` | Alt 快捷键交给 tmux，默认模式 |
| `tmkeys fish` | Alt 快捷键交给当前程序，包括 Fish、Helix、Yazi 等 |
| `tmkeys toggle` | 在两种模式之间切换 |
| `tmkeys status` | 查看当前模式 |
| `tmkeys --help` | 查看用法 |

- 只影响当前窗格，新窗格默认使用 `tmux` 模式。
- 状态栏右侧显示当前模式；已有窗格重新连接后保留原模式。
- `Ctrl+b` 前缀始终可用；Fish 的 `Alt+z/m/x/p/i` 不受影响。
- 复制模式使用自己的按键；先按 `q` 退出，再操作窗口。
- 在 tmux 外运行会提示无需切换，不修改 Fish 配置。

例如，要在 Yazi 中使用它自己的 Alt 按键，先运行 `tmkeys fish`，再打开 Yazi。退出后运行 `tmkeys tmux` 恢复。

## select_pac_or_aur

| 选项 | 执行命令 | 作用 |
| --- | --- | --- |
| `aur` | `aur` | 搜索并安装 AUR 软件包 |
| `pac` | `pac` | 搜索并安装仓库软件包 |
| `del` | `uninstall` | 选择已安装的软件包并卸载 |

使用方向键或 `w/s` 选择，Enter 确认，Esc 取消。此函数需要交互式 Fish 和 `fzf`。

## config.fish 中的函数

以下函数定义在本机 `config.fish`，不在本目录。

| 函数 | 作用 | 用法 |
| --- | --- | --- |
| `helix_smart` | 当前目录有 `.venv` 时先激活，再用 Helix 打开当前目录 | `helix_smart` 或 `Alt+z` |
| `y` | 打开 Yazi，退出后让 Shell 切换到最后所在目录 | `y` 或 `Alt+x` |
| `gow` | 使用 MinGW 和 CGO 构建 Windows amd64 程序 | `gow` 或 `gow 包路径` |
