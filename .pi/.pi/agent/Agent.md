# 编码前的文档检查

每次开始编写或修改代码前，必须先执行以下步骤：

1. 检查当前项目根目录是否存在 `README.md`、`Agent.md` 和 `ROADMAP.md`。
2. 对已存在的文件，先阅读并遵循其中的项目说明、开发约定和路线规划，不得直接覆盖。
3. 如果缺少任一文件，先查看项目目录结构、现有代码、配置及测试，了解项目的实际情况，再创建缺失文件并填写有依据的内容，不得只创建空文件或凭空编造。
   - `README.md`：说明项目用途、技术栈、安装方式、运行及测试方法。
   - `Agent.md`：说明目录结构、编码约定、开发流程和验证命令。
   - `ROADMAP.md`：记录已实现的功能、明确的待办事项和后续计划；无法从代码或现有资料确认的计划，应标注为待确认。
4. 完成上述检查和必要的文档补充后，再开始本次编码工作。

# 修改后的 Git 提交

1. 每次完成修改后，检查本次修改涉及的文件是否位于已有的 Git 仓库中；如果涉及，则在相应仓库中提交本次修改，提交说明必须使用中文，准确概括变更内容。
2. 只暂存和提交本次任务产生的修改，不得夹带用户其他未提交的改动；无实际变更时，不创建空提交。
3. 如果本次修改未涉及任何已有 Git 仓库中的文件，则无需提交。
4. 禁止自行运行 `git init` 或以其他方式创建 Git 仓库；Git 仓库由用户自行创建。
